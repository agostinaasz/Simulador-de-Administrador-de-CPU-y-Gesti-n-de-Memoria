Simulador de Memoria y Planificación de Procesos

Trabajo Práctico Integrador de Sistemas Operativos 2026.

El simulador implementa:

- Particiones variables
- Asignación de memoria Best-Fit
- Planificación SRTF
- Estados Nuevo, Listo, Listo y Suspendido, Ejecución y Terminado
- Máximo de 5 procesos admitidos simultáneamente.
- Cálculo de tiempo de retorno, tiempo de espera y rendimiento

Ejecución

Ejecutar:

python simulador.py

Luego ingresar el nombre del archivo que contiene los procesos.
